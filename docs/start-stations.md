# Стартовый экран и список станций

## Зачем нужна
Чтобы первокурсник мог начать квест и видеть, какие станции ему предстоит пройти.

## Пользовательский сценарий
1. Игрок заходит на сайт и вводит свое имя.
2. Нажимает кнопку «Начать квест».
3. Видит карту или список доступных станций (например, «Библиотека», «Столовая»).

## Критерий готовности
- Кнопка «Начать квест» работает и скрывает приветственный экран.
- Отображается список минимум из 3 станций.
- Первая станция доступна для клика.

## Риск или вопрос
- Что делать, если игрок не ввел имя? (Нужно ли ставить имя по умолчанию?)
