# Сценарий командного режима (4 игрока)

1. Игрок А создаёт команду, вводит название и получает короткий код.
2. Игроки Б, В, Г вводят код и присоединяются к команде.
3. Команда видит список участников и общий счёт 0.
4. Любой участник открывает станцию, читает задание и вводит ответ.
5. Система проверяет ответ и добавляет баллы в общий счёт команды.
6. После прохождения всех станций команда видит итоговый общий счёт.
