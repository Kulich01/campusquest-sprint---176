# Карточка загадки

## Зачем нужна
Чтобы показать игроку само задание (загадку) на выбранной станции и дать место для ввода ответа.

## Пользовательский сценарий
1. Игрок кликает на доступную станцию на карте.
2. Открывается всплывающее окно или новая страница с текстом загадки.
3. Внизу загадки есть поле для ввода текста и кнопка «Ответить».

## Критерий готовности
- Текст загадки читается без ошибок.
- Поле ввода активно (можно печатать).
- Кнопка «Ответить» реагирует на нажатие.

## Риск или вопрос
- Если загадка окажется слишком длинной, может сломаться верстка (дизайн).
