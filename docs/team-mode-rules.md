# Ограничения командного режима (минимальный вариант)

- Максимум 4 игрока в команде.
- Команду создаёт один игрок перед началом квеста.
- Присоединение — по короткому коду команды.
- Любой участник может отправить ответ на станции.
- Баллы суммируются в один общий счёт команды.
- Чат, приглашения по ссылке и отдельные роли НЕ входят в минимальный вариант.
- Push-уведомления НЕ входят в минимальный вариант.
